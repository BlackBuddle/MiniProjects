# MiniProjects

## 새 프로젝트 추가 방법

1. 저장소 루트에 프로젝트 이름으로 폴더를 만든다.
2. 폴더 안에 실행 방법을 적은 `README.md`를 둔다.
3. 위 **프로젝트 목록** 표에 한 줄을 추가한다.
